## Обо мне

Разработка, веб и полезные эксперименты.

Начинал с создания **Telegram-ботов** и небольших игровых проектов.  
Со временем участвовал в запуске **Minecraft-сервера**, который продолжает
работать и сегодня.

Позже перешёл к разработке частных Telegram-решений:

- автоматизация рабочих процессов;
- боты для запусков и сопровождения курсов;
- внутренние инструменты;
- закрытые пользовательские системы;
- интеграции с API и базами данных.

Последние несколько лет активно работаю в **криптоиндустрии**. Разрабатываю
Telegram-ботов, парсеры, market tools, системы аналитики, памп-детекторы
и сервисы для отслеживания активности рынка.

За спиной — **более двух лет активного коммерческого опыта в разработке**.

Параллельно работал **инженером-электроником в IT-отделе** и развиваю
собственные проекты. Среди личных запусков — проект в экосистеме
**TON** с автоматизированным Telegram-ботом и собственной аудиторией.

Сейчас создаю приватное крипто-сообщество и развиваю персональный сайт
с собственными инструментами и сервисами.
